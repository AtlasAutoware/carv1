# atlasautoware-cad</br>
**Explanation of organization:** </br></br>
*Components* folder - 3D models of parts used on our car</br>
*Mounts* folder - 3D models of the mounts we designed for the parts on our car</br>
*Templates* folder - 3D models of the original mounting system we designed (used to customize mounts for any parts)</br>
